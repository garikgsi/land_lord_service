backend/migration-drafts, namespace DomainMigrations зарегистрирован в Doctrine.
Применённые пользовательские миграции не менялись. К рабочей БД эти миграции
не применялись. Предметные ORM, сервисы и интерфейс ещё не реализованы.

Всего 20 таблиц. Структура и правила: [модель](../../../docs/domain-model-review.md).

objects.reading_day и contracts.contract_type_id обязательны без SQL DEFAULT.
При реализации сервер создания подставляет 25-е число и тип «аренда» соответственно.
Nullable meters.reading_day означает наследование графика объекта.

Одно начисление относится к договору и календарному месяцу. Корректировки содержат
полный набор замещающих параметров и окончательную сумму, включая 0. Актуальная
запись выбирается по created_at DESC, id DESC; корректировки не суммируются.
При отсутствии корректировок используются исходные значения начисления.
SQL не реализует автоматический расчёт, права доступа, жизненный цикл Space
и сальдо: это задачи предметных сервисов. Деньги и площади — NUMERIC без масштаба.

Проверка up/down, повторного применения, связей и ограничений:

```sh
docker compose exec -T php php bin/phpunit tests/Migration/DomainMigrationTest.php
```

Тесты запускают предметный Migrator внутри транзакции отдельной тестовой БД
и откатывают изменения. Не запускать bin/setup или bin/check для проверки
этих миграций на данном этапе: они применяют зарегистрированные миграции
вне откатываемого теста. После применения таблиц до создания ORM-модели
полная проверка синхронизации Doctrine ORM будет сообщать о лишних таблицах.
